# Methodology

1. Select two mentor-approved application profiles.
2. Verify the base QoO testbed works before modification.
3. Run six controlled impairment scenarios.
4. Run each scenario for Profile A and Profile B under identical conditions.
5. Record QoO, latency, throughput and at least one observable application metric.
6. Preserve raw outputs and link every chart to experiment IDs.
7. Explain how profile selection changes the interpretation of network quality.

Do not invent QoO mathematics or subjective user-experience claims without user testing.
