# Changelog

## 0.1.0 — 2026-10-09

- Added Tkinter desktop controller for the supplied QoO testbed API.
- Added single-workload runs for DASH/TCP, DASH/QUIC and active probes.
- Added six controlled scenarios, per-scenario repeats, raw run logs and CSV records.
- Added QoO profile loading and profile-parameter snapshots when exposed by the upstream API.
- Added API failure handling, conservative metric parsing, and manual attachment of real telemetry values.
- Added unit tests and a GitHub Actions workflow.
